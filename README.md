# yerincho04.github.io

Yerin Cho’s personal portfolio: https://yerincho04.github.io/

## Updating the portfolio

The homepage is a static website served directly from the root of the `main` branch by GitHub Pages. No build or dependency installation is required. The monochrome homepage uses native HTML disclosure controls and works without JavaScript or external fonts.

- `index.html`: page content and structure
- `styles.css`: responsive styles
- `assets/Resume_Yerin_Cho.docx`: downloadable résumé
- `.nojekyll`: serves the static files without Jekyll processing

Push changes to `main` to publish updates. Existing coursework and KartKing files retain their original paths.
